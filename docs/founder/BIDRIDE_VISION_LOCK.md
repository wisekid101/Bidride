## 9. THE BIDRIDE CONSTITUTION RULE `[FOUNDER-LOCKED]`
*(Source: Founder directive — "THE BIDRIDE CONSTITUTION". Extends the Authority Hierarchy above.)*

- **This Vision Lock defines what Bidiride SHALL become. The repository defines what Bidiride currently is.** The Vision Lock is the **destination**; the codebase is the **journey.**
- Where the two differ, the difference **SHALL** be recorded as a **Product Gap** (see §10). The gap **MUST NOT** be hidden, and **neither side may be silently changed** to mask it.
- **Product Gaps are NOT failures.** They are the **planned work** required to align the implementation with the Founder vision.
- **The Vision Lock SHALL NEVER be weakened** merely because the current implementation is incomplete. The existence of unfinished functionality **SHALL NEVER** be used to remove or weaken the Founder vision. An incomplete implementation is a Product Gap **to be closed** — never a reason to lower a Founder‑approved standard.
- **Tagging rule.** A Vision‑Lock rule the code does not yet meet remains stated at **full strength**; its *implementation status* is tagged `[KNOWN GAP]` or `[PARTIALLY IMPLEMENTED]`, and the gap is listed in the Progress Ledger. Approved *direction* is thereby never confused with delivered *functionality*, and the standard is never diluted.

## 13. THE PRODUCTION RULE `[FOUNDER-LOCKED]`
*(Source: Founder directive — "THE PRODUCTION RULE".)*

**Purpose.** Every engineering milestone **SHALL** move Bidiride closer to becoming a **production‑ready company.** Temporary demonstrations are valuable; **production systems are the objective.**

Every proposed milestone **SHALL** answer **all** of the following **before** implementation:
- How does this improve the **Rider**?
- How does this improve the **Driver**?
- How does this improve **Safety**?
- How does this improve **Trust**?
- How does this improve **Local Businesses**?
- How does this improve **Revenue**?
- How does this improve **AI Intelligence**?
- How does this improve **Scalability**?
- How does this improve the **long‑term Bidiride ecosystem**?

If these questions cannot be answered, a session **SHALL** explain why the milestone should be reconsidered **before** implementation.

**Technical completion alone SHALL NEVER be considered sufficient.** Business value, user value, production readiness, and Founder vision are **equally required.**
